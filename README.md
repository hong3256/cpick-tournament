# C-PICK 월례대회 대진표 (웹앱)

춘천 피클볼 동호회 **C-PICK** 월례대회 대진표를 짜고, 점수를 기록하고, 카톡으로 공유하는 앱입니다.
브라우저에서 열고 **홈 화면에 추가**하면 일반 앱처럼 아이콘으로 실행됩니다(PWA).

## 접속

- 웹: <https://hong3256.github.io/cpick-tournament/>
- 안드로이드 크롬: 주소창 오른쪽 `⋮` → **홈 화면에 추가** → **설치**
- 아이폰 사파리: 공유 버튼 → **홈 화면에 추가**

## 기능

| 기능 | 설명 |
| --- | --- |
| 참석자 자동 편성 | 이름·성별만 넣고 버튼 한 번 — 1부 청백전 대진과 2부 혼복 팀을 자동으로 |
| 점수 입력 | 점수를 넣으면 결과·코트·진출 팀이 바로 갱신 |
| 카톡 공유 | 명단·대진을 텍스트로 만들어 공유 |
| 대진표 이미지 저장 | 대진표 전체를 이미지 한 장으로 저장 |
| 인쇄 / PDF | 종이 대진표로 출력하거나 PDF로 저장 |
| 오프라인 | 한 번 열어 두면 인터넷 없이도 실행 (서비스 워커 캐시) |
| 실시간 동기화 | 구글 시트 + Apps Script 웹 앱과 5초마다 맞춤 · 기본은 보기 전용, 관리자 PIN 입력 시에만 수정 |

## 데이터

입력한 이름·점수는 **그 기기의 브라우저(localStorage)** 에 저장됩니다.
여러 기기에서 같은 대진표를 보려면 아래 **구글 시트 실시간 동기화**를 켭니다.

## 구글 시트 실시간 동기화

1. 시트(예: `C-PICK 월례대회 실시간 DB`)에서 **[확장 프로그램] → [Apps Script]** 를 열고
   `Code.gs` 내용을 붙여넣은 뒤 [배포] → [새 배포] → **웹 앱**
   (실행: 나 / 액세스: **모든 사용자**) → 나온 `…/exec` 주소를 복사합니다.
2. C-PICK 기본 웹 앱 주소는 앱에 **내장**되어 있어(설정 불필요) 열자마자 자동으로 연동됩니다.
   다른 시트·주소를 쓰려면 앱 상단 **[⚙️ 연동 설정]** 에 주소를 넣거나 `…/?api=<웹앱 주소>` 로 엽니다.
3. 연동되면 앱은 기본 **보기 전용**으로 열립니다. 수정하려면 **[🔐 관리자 입력]** → PIN을 넣으세요.
   관리자 모드에서는 명단·대진·점수 변경이 0.6초 디바운스로 시트에 자동 저장됩니다.

- 대진표 JSON은 시트 `A1`, 관리자 PIN은 `B1`(기본값은 시트에서 직접 바꿀 수 있음), 마지막 저장 시각은 `D1`에 기록됩니다.
- 연동하지 않으면(주소 없음) 예전처럼 누구나 바로 입력하는 로컬 모드로 동작합니다.
- 저장 요청은 `Content-Type: text/plain` 으로 보내 CORS 프리플라이트를 피합니다.

## 구성

```
index.html               대진표 앱 (단일 파일)
manifest.json            PWA 앱 정보
sw.js                    서비스 워커 (오프라인 캐시)
icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png / favicon.ico
tools/make_icons.py      앱 아이콘 생성 스크립트
tools/build_app.py       원본 HTML → index.html(PWA 메타 추가)
tools/test_local.py      로컬 동작 검증 (Playwright)
tools/test_sync.py       실시간 동기화 검증 (Apps Script GET/POST 모킹)
tools/test_apps_script.py  Code.gs 로직 검증 (doGet/doPost 모킹)
```

## 업데이트

`index.html` 등을 고쳐 `main` 브랜치에 푸시하면 1~2분 뒤 새 버전이 배포됩니다.
서비스 워커는 캐시를 먼저 보여 주고 뒤에서 새 파일을 받아 두므로, 두 번째 실행에서 최신 화면이 됩니다.
